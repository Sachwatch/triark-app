# 検索に載せない方法は、各ページの <meta name="robots" content="noindex"> の方です。
# こちらのファイルで通せんぼすると、検索避けにならないどころか逆効果になります。
#
#   robots.txt の Disallow … 「ページを読みに来ないで」
#   ページの noindex        … 「読んでいいが、検索結果には出さないで」
#
# Disallow で締め出すと、Google はページを読めないので noindex の指示も読めません。
# その結果、URLだけが検索結果に残ることがあります（Googleの説明どおり）。
# しかも、Facebook・LINE・Messenger などがリンクのカードを作るために
# 読みに来るのも、まとめて締め出してしまいます。
#
# なので、ここでは誰も止めません。検索避けは noindex に任せます。

User-agent: *
Disallow:
